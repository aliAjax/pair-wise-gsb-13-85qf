# 加油站班次交接

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。

## 现金袋拆箱移交

班次交接页提供现金袋从交班登记到接班拆箱、差异处理和结班的完整闭环：

1. **交班登记**：登记袋号、封签号、封签状态、封存金额和交班签字人。
   袋号重复、封签破损或金额缺失属于现场异常，允许登记但班次只能挂 **待核交**，
   不能正式交接、不能结束班次；异常更正清除后自动恢复。
2. **接班拆箱**：正式交接后接班方录入实点金额与假币金额，
   系统按封存金额自动判定长款、短款、假币（短款与假币可并存）。
3. **差异处理**：长款、短款、假币必须选择责任归属、写明情况，并由站长确认；
   未确认前原班次保持未结，不能结束班次。
4. **确认后只读与留痕**：站长确认后资料只读；确需改动时走“修正”，
   逐条保留旧值、新值、原因和操作人。改了金额会作废旧差异并重新生成，
   已结班次因此重开，待新差异重新确认后才能再结班。
5. **重开对应**：班次、现金袋、差异与处理通过 id 关联，
   刷新或重开页面后从 localStorage 恢复，对应关系不变。

### 代码分层（互不依赖界面/存储）

- `src/cashbag/types.ts`：现金袋、班次、差异、改动记录的资料模型
- `src/cashbag/rules.ts`：核对规则纯函数（袋号重复/封签破损/金额缺失、长短款与假币判定、结班条件）
- `src/cashbag/repository.ts`：localStorage 保存层与种子数据
- `src/cashbag/store.ts`：Pinia 编排层，组合资料、规则与保存，负责状态流转与留痕
- `src/components/CashBagHandover.vue`：界面
