# 加油站班次交接

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则自测：`npm run verify:cashbag`

这是一个功能最小闭环前端项目，数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。

## 现金袋拆箱移交

班次交接页（`src/cashbag/`）按四层分离，互不混用：

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 资料 | `cashbag/types.ts` | 班次、现金袋、差异、审计记录的数据结构 |
| 核对规则 | `cashbag/rules.ts` | 袋号重复/封签破损/金额缺失校验、长短款与假币计算、定责必填、可否结班（纯函数） |
| 保存 | `cashbag/storage.ts` | localStorage 存取与全部状态操作，每次写入追加审计记录（不依赖 Vue） |
| 状态 | `cashbag/useShiftStore.ts` | 响应式 store，自动持久化 |
| 界面 | `cashbag/components/*` | 登记表单、拆箱录入、现金袋卡片、班次工作区 |

业务闭环：

1. **交班登记**：逐袋登记袋号、封签、封存金额、签字人。袋号重复、封签破损、金额缺失时
   只能"待核交"，不能结束班次，接班也不能拆箱；核改完成后才能正常移交。
2. **接班拆箱**：录入实点金额与假币，自动计算差额（实点+假币−封存）并判定长款/短款/假币；
   有差异必须选择责任（交班方/接班方/站方承担）并写明情况，之后提交站长确认。未确认前原班次未结。
3. **站长确认**：站长签字后方可结班，结班后整班只读。
4. **重开与留痕**：已结班次可凭原因重开，班次、现金袋、差异与处理仍一一对应；确认后的改动
   必须填写原因，旧值、新值与原因逐条另存为审计记录，再次确认后恢复只读。
